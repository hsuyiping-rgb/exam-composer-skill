# 定期考察命題技能

國小定期考察命題輔助技能，定位為「生成端」工具，協助命題教師從命題範圍設定、教材整理、試題生成、查重、Word 輸出到 NotebookLM 歸檔完成一份可審查的定期考察成果。

本專案與 `esa-exam-review` 分工合作：本技能負責生成試題，`esa-exam-review` 負責審查端的歷屆試題查重與審查。

## 主要功能

- 命題條件設定：支援學年度、年級、科目、次別、單元範圍、題型配分與 Bloom 認知層次比例設定。
- 教材整理：協助教師從新北親師生平台確認康軒、翰林、南一教材清單；實際下載由使用者親手完成，Agent 只負責整理歸檔。
- 教材內容擷取：依命題範圍從課本、習作、教師手冊中擷取重點概念，並對應 108 課綱學習內容與學習表現。
- 雙向細目表骨架：依題型比例與 Bloom 比例建立題目配置，讓題型、分數、認知層次與單元知識點對齊。
- AI 試題生成：逐格產生全新題目、答案、課次與評量目標，避免直接使用出版社題庫。
- 素養題設計：素養題需標註情境範疇、學習表現、試題概念分析，非選擇題需附評分規準。
- 圖像題支援：若題目需要圖形、實驗圖、示意圖、座標圖、統計圖或看圖回答，需依題目文字判斷圖像需求；可參考課本、習作或教師手冊圖示裁切改標，必要時召喚全域 `draw` 技能產生或改版圖像。
- 歷屆試題查重：生成後送 `esa-exam-review` 比對 108~114 學年度歷屆考題；若有相同或過近題目，只重寫該格。
- Word 輸出：產出正式試題卷、教師解答卷與雙向細目表。
- 題目替換：使用者可指定單題替換，系統依原題型、認知層次與課次規格重新出題並查重。
- NotebookLM 歸檔：每一次命題任務建立單獨 NotebookLM 筆記本，不與其他學年度、年級、科目或次別混用。

## 命題流程

1. 設定命題範圍、配分、題型比例與 Bloom 比例。
2. 確認並整理出版社教材。
3. 擷取教材內容與課綱對應。
4. 建立雙向細目表骨架。
5. 逐題生成題目、答案、評量目標與必要圖像。
6. 執行歷屆試題查重。
7. 輸出 Word 試題卷、教師解答卷與雙向細目表。
8. 依使用者需求替換個別題目。
9. 建立該次命題專屬 NotebookLM 筆記本並匯入成果。

## 圖像題規則

命題時若題目文字需要圖像輔助，不能只留下「見圖」或空白佔位。常見情境包含：

- 數學幾何、座標、面積、體積、量測或統計圖表。
- 自然科實驗裝置、觀察圖、比較圖、流程圖或看圖回答。
- 素養題中的生活情境圖、場景圖或資料判讀圖。

處理原則：

- 優先參考課本、習作或教師手冊中的相關圖示，保留學科精準度。
- 可裁切、去除原標註、重新標上 A/B/C、甲/乙/丙、刻度、箭頭或作答框。
- 需要全新或改版圖像時，呼叫全域 `draw` 技能輸出到該次 `命題成果/.../images/`。
- 插入 Word 前必須檢查圖中文字、標籤、箭頭、比例與題幹一致，且不能洩漏答案。

## NotebookLM 規則

每一次命題任務都建立單獨的新 NotebookLM 筆記本，名稱格式：

```text
<學年度>_<年級>_<科目>_<次別>_命題成果
```

每本筆記本應加入：

- 本次教材 PDF。
- 正式試題卷、教師解答卷與雙向細目表。
- 查重報告、設定摘要與必要草稿。
- 本次科目需要的通用參考資料，例如 Bloom 分類、命題原則、108 領綱、素養導向文件與雙向細目表範本。

不再使用單一共用「命題成果筆記本」累積所有任務。

## 安全與授權邊界

- Agent 不得代使用者輸入校務系統、出版社平台或 OAuth 服務密碼。
- 出版社教材與歷屆考題可能有著作權或校務資料疑慮，不進 Git。
- 實際下載教材須由使用者親手點擊完成，Agent 不嘗試繞過瀏覽器下載限制。
- NotebookLM 未登入或未授權時，需由使用者自行完成登入授權。

## 版控策略

GitHub 只同步技能規則、專案說明與交接文件。以下內容不進版控：

- 出版社教材 PDF、ZIP。
- 歷屆考題、查重工作檔。
- 正式試題卷、教師解答卷、雙向細目表。
- NotebookLM 或校務平台的登入資訊。
